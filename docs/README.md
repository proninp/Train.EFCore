# Entity Framework Core in .NET

This repository is dedicated to learning and mastering **Entity Framework Core (EF Core)** - the modern data access technology for .NET applications.  
It serves as a personal playground for experimenting, exploring, and solidifying key concepts of ORM, data modeling, and database interactions.

## What’s inside

* Practical exercises covering the fundamentals and advanced features of EF Core  
* Example projects demonstrating different approaches to data access and persistence  
* Refactoring and optimization tasks to build real-world EF Core experience  
* Space for personal notes, experiments, and performance investigations

## Why this repository

* Gain a deep understanding of how EF Core works under the hood  
* Practice designing clean and maintainable data layers in .NET  
* Develop confidence in handling real-world database scenarios: from setup to migrations and performance tuning  
* Build a reusable knowledge base for future projects
